# 铜傀儡 · CopperGolem

> 下载游戏、管理账号、畅装内容——一次抵达。

![铜傀儡启动器](https://trae-api-cn.mchost.guru/api/ide/v1/text_to_image?prompt=modern%20Minecraft%20Bedrock%20game%20launcher%20desktop%20app%20dark%20glassmorphism%20UI%20with%20left%20navigation%20bar%20and%20content%20cards%20for%20game%20versions%20and%20mods%20clean%20futuristic%20design%20high%20detail&image_size=landscape_16_9)

铜傀儡是一款为 **Minecraft Bedrock** 打造的现代化启动器。它把**版本下载、账号登录、游戏内容**装进同一个干净、迅捷的入口——启动器，本该如此。

## 为什么用铜傀儡

- **一站管理** —— 游戏版本、账户、启动，一个入口全搞定，不再来回倒腾。
- **内容中枢** —— 地图、光影、资源与模组，逛逛就能装，装好即玩。
- **轻巧迅捷** —— 启动快、占用低，把宝贵的资源留给游戏本身。
- **开放可扩展** —— 模块化架构，需要什么装上即用，社区可共建、可生长。

## 设计理念

我们相信：**把复杂藏起来，把好用留下**。

铜傀儡遵循克制、现代、以人为本的设计。几乎所有操作都有清晰回馈，动画顺滑自然，界面主题随你的夜幕或日光随时切换。它不喧哗，但它可靠。

## 为谁而生

- **玩家** —— 下载游戏、登录正版账号、一键开玩，轻松管理多个版本与内容。
- **内容作者** —— 在统一的内容中心分发你的作品，触达更广的玩家。
- **开发者** —— 基于开放的模块体系扩展启动器，无需改动内核，即可搭建自己的玩法。
