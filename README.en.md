> CopperGolem is in early development; public releases are test versions. Back up important worlds and data before use. Compatibility with older setups is not guaranteed after Minecraft or launcher updates.

CopperGolem is a modern launcher built for Minecraft Bedrock. It unifies **version download, account sign-in, and game content** into one clean, fast entry point — so you spend less time getting ready and more time playing.

## Quick Start

> [!IMPORTANT]
> Always install from official sources, and start from a clean environment.

1. Download the latest installer from the [Releases](https://github.com/copper-lamp/CopperGolemLauncher/releases) page.
2. Install and launch CopperGolem.
3. Sign in with your Minecraft Bedrock account.
4. Download a game version and any content you want, press play, and enjoy.

## Why CopperGolem

- **Everything in one place** — manage game versions, accounts, and launching from a single entry; no more bouncing between tools.
- **A home for content** — maps, shaders, resources, and mods: browse, install, and play.
- **Light and fast** — quick to start, low overhead, keeping resources where they matter: your game.
- **Genuine experience** — native support for Minecraft Bedrock account sign-in.
- **Open and extendable** — a modular architecture you can grow with; install what you need, and let the community build together.
- **Human-centered** — details matter; the interface theme shifts naturally with your night or daylight.

## Made For

## FAQ

### What is CopperGolem?

CopperGolem is an extendable, modular launcher for Minecraft Bedrock Edition. It brings version download, account sign-in, and game content management together into one clean, efficient desktop entry point.

### Do I need a genuine account?

CopperGolem natively supports logging into your Minecraft Bedrock account for the full online and content experience.

### Can I install maps, shaders, resources, and mods?

Yes. CopperGolem ships with a built-in **content center** module for browsing, downloading, and installing game content; its modular architecture also lets you extend more content sources on demand.

### Will other platforms be supported?

Currently targeting Windows x64 Bedrock. The kernel is designed with platform abstraction, keeping a boundary open for more platforms.

### Where is the safest place to download?

Always get builds from this repository's [Releases](https://github.com/copper-lamp/CopperGolemLauncher/releases) or official announcement channels, and avoid unknown distribution sources.

## Known Limitations

- The project is in early development; the interface and capabilities are actively changing and do not represent the final form.
- Currently supports Windows x64 Bedrock only; other platforms are not yet available.
- Some capabilities (e.g. fuller account and session management) are still being built.
- Compatibility may need to be re-verified after Minecraft or system updates.
